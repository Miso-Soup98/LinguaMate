# 语伴 LinguaMate

原创的 Chrome 语言学习插件。它参照 Language Reactor 的**公开功能思路**，用自己的界面和代码实现：在 YouTube 上看视频时显示双语字幕、点词查询、逐句控制和生词本。

本项目与 Language Reactor / Language Learning with Netflix **没有从属关系**，不复制其源码、商标或界面。

## 能做什么

- YouTube 双语字幕：学习语言 + 母语对照
- 优先使用视频自带字幕；没有对应语言时，用 YouTube 翻译轨道生成译文
- 自动字幕会按标点和时长合并成更完整的句子
- 点词查词典，右键直接收藏
- 听写模式：字幕默认隐藏，鼠标悬停才显示
- 逐句暂停，以及 A / S / D 上一句、重播、下一句（按住可预览）
- 右侧字幕列表、生词和学习覆盖率
- 生词本、间隔重复闪卡、导出 CSV / Anki
- 任意网页：右键「用语伴查阅」或「用语伴阅读」

## 明确不做的部分

- **不支持 Netflix**。其字幕受版权和 DRM 保护，这里不会拦截或复制。
- 不做 Language Reactor 的账号同步、内容目录站、Lexa/Aria AI 导师，以及他们的付费 ASR 服务。

## 安装

1. 打开 Chrome，进入 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本文件夹 `language_reactor`
5. 打开任意带字幕的 YouTube 视频即可使用

首次使用建议：在插件弹窗里把「学习语言」设为视频语言，把「母语 / 译文」设成中文。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| A | 上一句。按住会暂停预览 |
| S | 重播当前句。按住会暂停预览 |
| D | 下一句。按住会暂停预览 |
| 右键单词 | 不打开词典，直接加入生词本 |

## 权限说明

- `storage`：保存设置和生词
- `contextMenus` / `activeTab` / `scripting`：网页阅读
- YouTube 与翻译接口：拉取字幕和词义
